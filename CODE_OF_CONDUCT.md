# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, assume good intent, give constructive feedback, and accept it gracefully.
Harassment, insults, and personal or political attacks are not tolerated, in issues, pull requests or anywhere else
this project is discussed.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub ([@dymchenkko](https://github.com/dymchenkko)).
All reports are reviewed and handled confidentially. The maintainer may remove comments, commits or contributions
that break this code, and may ban contributors who do so repeatedly.
